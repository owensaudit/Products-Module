# Products Module

Curated Super C motorhome recommendations for owners stepping up from a **Black Series HQ21**.

## Who it’s for

- Want a **bigger living box** than the HQ21’s 21 ft interior
- Prefer **heavy-duty** truck-chassis / Super C builds
- Care about a **classy** residential finish
- Need **rear clearance** for a steep driveway (especially when reversing)

## Top picks ranked in-app

1. **Jayco Seneca XT 29T** — best steep-driveway geometry
2. **Dynamax Isata 5 28SS** — classiest compact Super C
3. **NeXus Rebel 30R** — steel-cage heavy build
4. **Renegade Verona 36VSB** — luxury larger box (test the driveway)
